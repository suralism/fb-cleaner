# 🧹 FB Activity Cleaner (v2.3)

> **Chrome Extension สแกนและลบกิจกรรม Facebook อัตโนมัติ** (โพสต์, แท็ก, ความรู้สึก, ความคิดเห็น) สะดวก รวดเร็ว พร้อมระบบป้องกันโดน Facebook บล็อก

---

## 🌟 คุณสมบัติเด่น (Features)

- 📦 **รองรับ 2 โหมดการทำงาน (Dual Modes)**
  - **Batch Selection Mode:** เลือก Checkbox หลายรายการแล้วลบพร้อมกัน (เร็วกว่า)
  - **One-by-One Mode:** กดจุดสามจุด (...) แล้วทำรายการทีละอันอย่างแม่นยำ (ละเอียดกว่า)
- 🎯 **รองรับการจัดการหลายประเภทกิจกรรม (Multi-Action Support)**
  - 🗑️ **Move to Trash / Delete:** ย้ายไปถังขยะ / ลบโพสต์
  - 🏷️ **Remove Tag:** เอาแท็กออกจากโพสต์ที่คุณถูกแท็ก
  - 🙈 **Hide from Profile:** ซ่อนโพสต์จากโปรไฟล์/ไทม์ไลน์
  - 💔 **Remove Reaction / Unlike:** เลิกกดไลก์ / ยกเลิกการแสดงความรู้สึก
- 🛡️ **ระบบป้องกัน Rate Limit อัตโนมัติ (Anti-Block Safety)**
  - ตรวจจับข้อความแจ้งเตือนบล็อกชั่วคราวจาก Facebook และสั่ง `Pause` อัตโนมัติทันที เพื่อความปลอดภัยของบัญชี
- 🚨 **ปุ่มหยุดฉุกเฉิน (Emergency Hotkey)**
  - กด **`Alt + S`** บนหน้าเว็บ Facebook เพื่อหยุดการทำงานของสคริปต์ได้ทันที
- 📊 **บันทึกสถิติสะสม (Persistent Statistics)**
  - สรุปยอดลบในเซสชันปัจจุบัน และยอดลบสะสมทั้งหมด (All-Time Total) แม้ปิดเบราว์เซอร์ไปแล้ว
- 🎵 **เสียงแจ้งเตือนอัตโนมัติ (Audio Chime Alerts)**
  - สังเคราะห์เสียงตอบรับเมื่อทำรายการเสร็จ หรือแจ้งเตือนเมื่อเกิดข้อผิดพลาดผ่าน Web Audio API
- 🎨 **หน้าตาผู้ใช้สวยงามทันสมัย (Modern Glassmorphism UI)**
  - ออกแบบสวยงาม รองรับทั้ง Popup Window และ Chrome Side Panel

## 📥 วิธีติดตั้ง (Installation Guide)

1. **ดาวน์โหลด/เตรียมไฟล์:**
   - ดาวน์โหลดโฟลเดอร์โปรเจกต์ `fb-cleaner` หรือ Clone Repository ลงในคอมพิวเตอร์ของคุณ

2. **เปิดหน้า Extensions ใน Google Chrome หรือ Microsoft Edge:**
   - ใน Chrome: พิมพ์ `chrome://extensions/` ที่ช่องที่อยู่ URL
   - ใน Edge: พิมพ์ `edge://extensions/`

3. **เปิดใช้งาน Developer Mode (โหมดนักพัฒนา):**
   - เปิดสวิตช์ **Developer mode** ที่มุมขวาบนของหน้า Extensions

4. **โหลด Extension เข้าสู่เบราว์เซอร์:**
   - กดปุ่ม **Load unpacked** (โหลดส่วนขยายที่ถอดรหัสแล้ว)
   - เลือกโฟลเดอร์ `fb-cleaner`

## 🚀 วิธีใช้งาน (How to Use)

1. เข้าเว็บ [Facebook](https://www.facebook.com) แล้วไปที่ **โปรไฟล์ของคุณ**
2. กดปุ่มจุดสามจุด (**...**) ข้างโปรไฟล์ → เลือก **Activity Log** (*บันทึกกิจกรรม*)
3. คลิกเลือกหมวดหมู่ที่ต้องการทำความสะอาด (เช่น *Your Posts*, *Activity You're Tagged In*, *Interactions*)
4. คลิกไอคอน **FB Activity Cleaner** บนแถบส่วนขยาย หรือเปิด Side Panel
5. **ตั้งค่าตามต้องการ:**
   - **Action Delay:** แนะนำ **3.0 - 5.0 วินาที** (ยิ่งสูง ยิ่งปลอดภัยจาก Rate Limit)
   - **Target Action:** เลือกการกระทำที่ต้องการ (ลบ / เอาแท็กออก / ซ่อน / เลิกถูกใจ)
   - **Deletion Mode:** Batch Mode หรือ One-by-One Mode
6. กดปุ่ม **▶ Start** เพื่อเริ่มการทำงาน

## ⚠️ ข้อควรระวังและการใช้งานอย่างปลอดภัย (Safety Guidelines)

- **ความเร็วในการทำงาน (Delay):** ไม่ควรตั้ง Delay ต่ำกว่า 2.0 วินาที เพื่อป้องกัน Facebook ตรวจจับการกดถี่เกินไป
- **การลบจำนวนมาก:** หากต้องการลบหลายพันรายการ แนะนำให้แบ่งทำเป็นรอบๆ รอบละ 100-200 รายการ แล้วพัก 10-15 นาที
- **การหยุดฉุกเฉิน:** หากสคริปต์กดผิดรายการ สามารถกดปุ่ม **`Alt + S`** บนคีย์บอร์ด หรือกดปุ่ม **Stop** บน Extension ได้ทันที
